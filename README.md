# Fasting Timer

A simple intermittent fasting timer, installable as a PWA.
Generated by Claude Opus 4.7.

No backend at all, meaning 100% privacy as data never leaves your device.

Live: https://asentahchiyski.github.io/fasting-timer/

## Features

- Start, end, or discard a fast; edit start and end times after the fact
- Fasting stages from fed through ketosis and autophagy to prolonged fasting
- History with average and longest fast, goal streaks, and a chart of recent fasts
- Confetti and a motivational message when you complete a fast
- Custom accent color, light/dark theme, timezone, and 12/24-hour format
- English and Bulgarian
- Works offline

## Your data

Everything is stored in the browser (IndexedDB). Mobile browsers can sometimes
clear that storage, so the app keeps extra copies:

- Asks the browser for persistent storage
- Mirrors the data to localStorage and to a backup JSON file (a file you choose
  in Chromium browsers, otherwise a private file in browser storage)
- Restores from those copies automatically if the main database is empty
- Manual export/import as a JSON file from Settings, e.g. to move to another device

## Development

Requires Node.js.

```sh
npm install
npm run dev        # dev server on http://localhost:5173
npm run typecheck  # type check
npm run build      # type check + production build to dist/
npm run preview    # serve the built dist/
```

Built with React 18, TypeScript, Vite, Tailwind CSS, and Dexie.

## Deployment

Pushing to `master` builds the app and publishes it to GitHub Pages via
`.github/workflows/deploy.yml`.
